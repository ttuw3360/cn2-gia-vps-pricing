## 下单前确认三件事

1. **续费价。** 首期 ¥299/年的年付款，第二年续多少，现有资料里没有答案。年付产品尤其要先问清楚，一次性付一年的钱，第二年翻倍的话前期的便宜就白算了。

3. **退款。** 有没有几天内无理由退款、按什么条件退、流量用超了还退不退，资料里同样没有。第一次买这家的机器，建议先用月付试一个月，把路由和三网延迟摸清楚，再决定要不要切年付。
